# Third-Party Components

This plugin bundles the following packages so KiCad's embedded Python can open
and render PDF files without a Codex runtime or another plugin:

- `pypdf 6.10.0` (`BSD-3-Clause`)
- `pypdfium2 5.12.1` (`BSD-3-Clause`, `Apache-2.0`, and dependency licenses)

The corresponding wheel metadata and complete license files are included under
`vendor/pypdf-6.10.0.dist-info` and
`vendor/pypdfium2-5.12.1.dist-info`.
